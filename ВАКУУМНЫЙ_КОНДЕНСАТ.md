## 1. Архитектурное позиционирование

Домен относится к кластеру **B. Knowledge Graph** (База знаний), но выделяется как специализированный научно-исследовательский контур.

- **Роль:** Фундаментальный портал открытой науки (Open Science).
- **Связь с САМ:** Использует принципы DRY (переиспользование `shared-assets`), Mobile-First и Knowledge as Code.
- **Отличие от других доменов:** В отличие от RSS-сайтов (кластер A) и платформы САН (кластер C), данный домен требует интерактивной визуализации данных (графики эволюции плотности, функции масс черных дыр) и строгого математического формализма.

## 2. Технологический стек

- **Генератор сайтов:** Astro (Islands Architecture).
  - *Обоснование:* Необходимость смешения статического контента (текст статьи, LaTeX-формулы) и динамических "островов" (интерактивные графики на JS/Canvas/WebGL) без полной гидратации всей страницы. Astro обеспечивает лучшую производительность LCP и совместимость с `shared-assets`, чем Hugo для сложных интерактивных задач.
- **Хостинг:** GitHub Pages (ветка `main`).
- **Вычисления:** Python scripts (NumPy, SciPy, Matplotlib) для генерации данных перед сборкой сайта. Результаты коммитятся в репозиторий как артефакты (`public/data/*.json`).
- **Формулы:** KaTeX или MathJax (через плагин Astro).

## 3. Интеграция с экосистемой blago-nko

1. Shared Assets:
   - Импорт базовой темы CSS (`theme-vacuum.css`, наследует переменные из `shared-assets/css/base.css`).
   - Использование общих компонентов: `site-title.html`, `footer.html`, `cookie-consent.js`.
   - Единый favicon и структура навигации.
2. СУМКа (Оркестратор дистрибуции):
   - Регистрация источника RSS `/feed.xml` в конфигурации СУМКа.
   - Теги для автопостинга: `#наука`, `#космология`, `#VCHU`, `#darkmatter`.
3. Identity Graph:
   - Автор профиля привязывается к `identity_graph.json` с ролью `Researcher` / `Author`.
4. Лицензионное исключение (см. раздел 5):
   - Данный домен является единственным исключением из общего правила ЛИЦ.md (AGPLv3 + CC BY-NC 4.0) в пользу более свободных лицензий для максимизации научного влияния.

- **Text/Idea/Paper:** **CC BY 4.0** (Creative Commons Attribution 4.0 International).
  - *Разрешает:* Копирование, распространение, адаптацию и коммерческое использование при условии указания авторства.
  - *Цель:* Максимальная цитируемость и свободное распространение идей в научном сообществе.
- **Code/Math Scripts:** **MIT License**.
  - *Разрешает:* Свободное использование кода в любых целях, включая закрытые проекты, при сохранении уведомления о лицензии.

## 6. Принципы разработки (VAC-)

Все изменения вносятся только через Pull Requests с префиксом `VAC-`.
Обязательные проверки CI:

1. `architecture-check`: Валидация наличия JSON-LD, sitemap, robots.txt.
2. `latex-lint`: Проверка корректности математических выражений.
3. `data-validation`: Проверка целостности JSON-файлов с расчетными данными.
