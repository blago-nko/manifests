# Чек-лист пилотной миграции obrazslov.ru (MIG-002)

> Документ описывает шаги и критерии приёмки пилотной миграции сайта obrazslov.ru с Blogger на Hugo.

## Этап 1: Экспорт контента

- [x] Получить Blogger Blog ID и API Key
- [x] Запустить scripts/blogger_export.py для экспорта постов
- [x] Проверить: все посты экспортированы (сравнить с количеством в Blogger)
- [ ] Запустить scripts/media_downloader.py для скачивания изображений
- [ ] Проверить: все изображения скачаны в static/images/
- [ ] Запустить scripts/url_mapping.py для генерации маппинга URL
- [ ] Проверить: data/url_mapping.json содержит все старые URL

## Этап 2: Настройка Hugo-сайта

- [ ] Репозиторий blago-nko/obrazslov создан
- [ ] shared-assets подключён как submodule
- [ ] config.toml настроен с permalinks /YYYY/MM/slug.html
- [ ] Локальный hugo server запускается без ошибок
- [ ] Все посты отображаются корректно

## Этап 3: Проверка контента

- [ ] Все посты перенесены (количество совпадает)
- [ ] Изображения отображаются (локальные пути работают)
- [ ] Форматирование сохранено (заголовки, списки, ссылки)
- [ ] YouTube-видео встроены через шорткод
- [ ] Метки Blogger -> Hugo tags/categories

## Этап 4: Проверка URL

- [ ] Permalinks соответствуют схеме Blogger: /YYYY/MM/slug.html
- [ ] Все старые URL маппятся на новые (через url_mapping.json)
- [ ] 301-редиректы настроены (Cloudflare Page Rules)

## Этап 5: Проверка SEO

- [ ] sitemap.xml генерируется автоматически
- [ ] robots.txt присутствует
- [ ] Meta-описания из front matter отображаются
- [ ] Open Graph и Twitter Cards присутствуют в head
- [ ] JSON-LD разметка (Article) присутствует

## Этап 6: Проверка артефактов СУМКа

- [ ] Mobile-first layout работает (breakpoints 360/768/1024)
- [ ] Шапка и подвал отображаются
- [ ] CookieConsent.js загружается
- [ ] Футер-лицензия CC BY-NC 4.0 присутствует
- [ ] Блок «Об экосистеме» со ссылками на домены

## Этап 7: Деплой и проверка

- [ ] GitHub Pages деплой успешен (workflow зелёный)
- [ ] Staging-URL доступен
- [ ] Все страницы загружаются без ошибок 404
- [ ] Uptime-мониторинг 48 часов без сбоев

## Критерии приёмки пилота

Пилот считается успешным, если:

1. Все 7 этапов пройдены (все чекбоксы отмечены)
2. Контент полон (количество постов совпадает с Blogger)
3. URL-схема сохранена (старые адреса работают через 301)
4. SEO-элементы присутствуют (sitemap, meta, OG)
5. Артефакты СУМКа реализованы (mobile-first, cookie, лицензия)
6. Uptime 48 часов >= 99%

После успешного пилота — rollout на остальные 13 сайтов (Этап 3 INFRA-047).
