# Границы ответственности: Тема vs Сайт (Theme Boundary Definition)

**Версия:** 1.0  
**Дата:** 2026-09-26  
**Статус:** Активен  

## Цель
Документ фиксирует четкое разделение логики рендеринга, стилей и конфигурации между общим репозиторием ассетов (`blago-nko/shared-assets`) и индивидуальными репозиториями сайтов экосистемы (например, `obrazslov`, `partnerstvo`). Нарушение этих границ приводит к «расползанию» кода и невозможности централизованного обновления.

## 1. Общая зона (Shared Zone)
*Хранится в `themes/shared-assets`. Изменяется только через Pull Request в этот репозиторий.*

| Компонент | Что входит | Правило |
| :--- | :--- | :--- |
| **Design Tokens** | CSS-переменные (`--color-primary`, `--font-size-h1`), шрифты, отступы, border-radius. | Никакой хардкод hex-кодов или px-значений в шаблонах сайтов. Все значения берутся из токенов. |
| **Layout Structure** | Шапка (`site-title.html`), Футер, Сетка (`grid`), Логика меню (desktop/mobile). | Сайты не могут переопределять структуру HTML-разметки шапки/футера локально. |
| **Components** | Карточки постов (`.post-card`), Кнопки, Бейджи тегов, Шорткоды (`img`, `video`). | Если компонент нужен двум и более сайтам — он должен быть вынесен в тему. |
| **SEO & Meta** | JSON-LD partials (`jsonld-article.html`, `breadcrumb.html`), OG tags, Twitter cards. | Генерация метаданных полностью делегирована теме. Сайты предоставляют данные через Front Matter. |
| **Scripts** | CookieConsent.js, StickyBottomBar.js, Analytics hooks. | JS-логика взаимодействия с UI принадлежит теме. |

> **Запрет:** В репозитории сайта запрещены файлы `layouts/_default/*.html`, если они дублируют логику темы. Исключение: специфические типы страниц, отсутствующие в теме (например, лендинг с уникальной версткой).

## 2. Индивидуальная зона (Site Specific Zone)
*Хранится в репозитории конкретного сайта (например, `obrazslov/config.toml`).*

| Элемент | Что входит | Где задавать | Пример |
| :--- | :--- | :--- | :--- |
| **Identity** | Название сайта, описание, автор по умолчанию, язык. | `[params]` в `config.toml` | `title = "Образ слов"` |
| **Logo & Branding** | Путь к логотипу, размер логотипа (если отличается от стандарта). | `[params.logo]` | `path = "/logo.svg"`, `size = 144` |
| **Color Override** | Редкие случаи смены цветовой схемы (только через переменные!). | `[params.colors]` | `primary = "#FF5733"` (используется в CSS vars fallback) |
| **Navigation Menu** | Список пунктов меню, их порядок и URL. | `[[menu.main]]` | `{ name = "Статьи", url = "/posts/" }` |
| **Social Links** | Иконки соцсетей в футере/шапке. | `[params.social]` | `telegram = "...", vk = "..."` |
| **Content Taxonomy** | Активные таксономии (tags, categories). | `[taxonomies]` | `tag = "tags"` |
| **Build Config** | BaseURL, environment flags, plugins. | Верхний уровень `config.toml` | `baseURL = "https://obrazslov.ru/"` |

## 3. Пограничная зона (Conditional Logic)
Логика внутри темы, управляемая параметрами сайта.

| Сценарий | Реализация в теме | Управление из сайта |
| :--- | :--- | :--- |
| **Наличие логотипа** | `if isset(params.logo)` -> показать SVG/PNG. Иначе -> текст. | Удалить секцию `[params.logo]`, чтобы включить текстовый фоллбэк. |
| **Тип страницы** | Partial `jsonld-article.html` рендерится только `if .IsPage`. | Не требуется настройка. Автоматически игнорирует статические страницы. |
| **Мобильное меню** | JS/CSS скрывает/показывает `sticky-bottom-bar` на брейкпоинтах. | Флаг `enable_sticky_bar = false` в params (если нужно отключить для лендинга). |

## 4. Чек-лист соблюдения границ (Audit Checklist)
Перед мержом PR в любой сайт экосистемы проверить:
1.  [ ] Нет ли файлов `layouts/partials/header.html` или `footer.html` в корне сайта? (Должны быть в теме).
2.  [ ] Нет ли хардкода цветов (`#FFF...`) в Markdown или HTML внутри сайта? (Должны быть классы или переменные).
3.  [ ] Все ли изображения используют шорткод `{{< img >}}`? (Нет прямых `<img>` тегов).
4.  [ ] Есть ли в `config.toml` параметры, дублирующие дефолтные значения темы без необходимости? (Удалить лишнее).
