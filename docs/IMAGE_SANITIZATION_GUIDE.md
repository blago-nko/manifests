# IMAGE SANITIZATION GUIDE — конвейер обработки изображений

> Нормативное руководство (САМ, принцип 2.5). Обязательно для всех изображений экосистемы.

## 5 этапов обработки
1. **EXIF-очистка** — `exiftool -all=` (удаление метаданных: геолокация, камера).
2. **Конвертация** — WebP/AVIF (`sharp` / `cwebp`).
3. **Ресайз** — 4 размера: 400 / 800 / 1200 / 1600 px. Максимум — **1600 px**.
4. **Дедупликация** — pHash + расстояние Хэмминга (порог ≤ 5).
5. **Водяной знак** — опционально, по флагу.

## Почему ≤1600px
- Лимит Google для безлимита — ≤2048 px; режем до 1600 px для LCP и веса страницы (САМ 1.9, 2.5).
- Загрузка в Blogger изображений >1600 px **запрещена**.

## Хранение результатов
- WebP ≤1600 px → **Blogger** (основной слой).
- PDF и `media_passport.json.gz` → **Cloudflare R2**.
- Видео — не хранится (VK Video / Rutube / YouTube, oEmbed).

## Применение при миграции
Каждое изображение из дампа Blogger проходит все 5 этапов до загрузки в новое хранилище
и замены URL в контенте (скрипт Фазы 0 — `sanitize_images.py`).
