# BLOGGER IMAGE STORAGE GUIDE

> Нормативное дополнение к САМ §2.2–2.3 (эволюционная модель хранения медиа).

## Роль
Blogger — основной («холодный») слой хранения изображений для всех 14 доменов + архив.

## Условие безлимита
- ресайз ≤1600 px (Image Sanitization Pipeline);
- формат WebP/AVIF; EXIF удалён.

## Загрузка и замена URL
1. Санитизация изображения (см. IMAGE_SANITIZATION_GUIDE.md).
2. Загрузка в Blogger (API или скриптом миграции).
3. Замена старых URL в контенте на новые `*.bp.blogspot.com`.
4. Карта URL (метаданные) — еженедельный бэкап в Git (САМ 2.2, 3.16).

## Запреты
- видео и PDF в Blogger (PDF → R2);
- загрузка оригиналов >1600 px;
- удаление изображений из Blogger после миграции (архив).

## Защита от vendor lock-in
- аварийная миграция: `migrate_blogger_to_r2.py`;
- резервное копирование: принцип 3-2-1, вторая копия метаданных — Yandex Object Storage
  после переезда на Cloudflare (САМ, протокол 015.3).
