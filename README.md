## 🏗️ Ключевые архитектурные решения

- **Технологический стек:** Hugo (статические контентные сайты) + Next.js (динамическая платформа САН).
- **Хранение медиа:** Эволюционная модель Blogger (основной, безлимит) + Cloudflare R2 (PDF, медиа-паспорта).
- **Обработка изображений:** Единый 5-этапный Image Sanitization Pipeline (EXIF → WebP → ресайз ≤1600px → pHash → водяной знак).
- **Безопасность:** Соответствие 152-ФЗ через российский ПДн-шлюз (Yandex Cloud Functions) + шифрование AES-256-GCM.
- **Стандарты данных:** Адаптация под RESO Data Dictionary и OData v4.0 для B2B-интеграций.
