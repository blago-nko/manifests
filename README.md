##  Быстрый старт

### Для новых участников
1. Изучите [САМ.md](./САМ.md) — архитектура и технологический стек
2. Прочитайте [СУМКа.md](./СУМКа.md) — процессы разработки
3. Ознакомьтесь с [ЛИЦ.md](./ЛИЦ.md) — правила лицензирования

### Для архитекторов
1. Внесите изменения в соответствующий манифест
2. Создайте Pull Request с обоснованием
3. Получите минимум 2 approval от maintainers
4. Слейте в main после прохождения проверок
