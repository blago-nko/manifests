## 🤖 ВАЖНО: Инструкции для ИИ-агентов и контрибьюторов

Вся разработка и внесение изменений в экосистему ведутся по строгим архитектурным протоколам:

- ☁️ **Cloud-Only Development** — запрет на локальное клонирование и коммиты
- 🔀 **Strict Branch Protocol** — обязательные PR, специфичные префиксы веток, атомарность изменений
- 🏛️ **Codespaces-Only Policy** — изменения манифестов только через GitHub Codespaces (пошагово для человека — AGENTS.md §5)
- 📝 **Суффикс `-н`** — историческая метка «Нормативная версия» (перенос из локальной среды в GitHub)

⚠️ **Перед началом работы, генерацией кода или предложением изменений ОБЯЗАТЕЛЬНО ознакомьтесь с файлом [AGENTS.md](./AGENTS.md).**

Прямой коммит в `main` категорически запрещён и может заблокирован Branch Protection Rules.

## 🏗️ Технологический стек

Экосистема использует гибридную архитектуру, оптимизированную под бесплатные квоты:

- **Hugo** — статические контентные сайты (11 RSS-сайтов, первичная версия ГРЕК-ПАНТЕОН)
- **Astro** — целевая платформа для ГРЕК-ПАНТЕОН (после решения Арх. Комитета)
- **Next.js App Router** — динамическая платформа САН (SSR, Edge Middleware, API Routes)
- **Supabase / PostgreSQL** — реляционное ядро САН (лимит Этапа 0: до 100 000 объектов)
- **GitHub Pages** — хостинг статических сайтов
- **Vercel** — PaaS для платформы САН
- **Blogger** — витрина НКО и основное хранилище изображений (безлимит при ресайзе ≤1600px)
- **Cloudflare R2** — только для PDF и `media_passport.json.gz` (категорический запрет на хранение видео и изображений)

### 📊 Бюджет инфраструктуры

Все архитектурные решения подогнаны под бесплатные квоты:

- **Supabase Free:** 500 МБ (жёсткий лимит Этапа 0: ≤100 000 объектов недвижимости)
- **GitHub Pages:** безлимит
- **Blogger:** безлимит изображений при ресайзе ≤1600px
- **Cloudflare R2:** 10 ГБ (только PDF/медиа-паспорта)
- **Google Sheets API:** 500 запросов/100 сек/пользователь

## 🔐 Безопасность и 152-ФЗ

- **Локализация ПДн:** Российский ПДн-шлюз на Yandex Cloud Functions
- **Шифрование:** AES-256-GCM до записи в Supabase (тип данных `bytea`)
- **Изоляция контура:** САН развёрнут под отдельным аккаунтом `can-secure-dev`
- **Crawler Rate Limiting:** Защита БД от ИИ-ботов через Next.js Edge Middleware
- **Image Sanitization Pipeline:** 5-этапная очистка изображений (EXIF → WebP → ресайз ≤1600px → дедупликация → водяной знак)
