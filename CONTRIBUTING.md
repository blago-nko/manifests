# Вклад в manifests

Спасибо, что хотите внести вклад! Документ описывает процесс контрибуции.

## С чего начать

1. Прочитайте [README.md](README.md) — обзор проекта.
2. ИИ-агентам: [AGENTS.md](AGENTS.md) обязателен к исполнению.
3. Выберите задачу в [TASKS.md](TASKS.md) или предложите свою через Issue.

## Процесс веток и PR

- Имена веток по AGENTS.md §5.5.1: `тип/краткое-описание` (docs/, fix/, feat/, chore/).
- Один PR = одна задача; префиксы заголовков: `docs:`, `fix:`, `feat:`, `chore:` или `INFRA-NNN:`.
- Все проверки CI должны быть зелёными до мержа.
- Только squash-merge; ветка удаляется после мержа.

## Требования

- Markdown по markdownlint (конфиг `.markdownlint.yaml`); локальная проверка:

    npx markdownlint-cli2 "ФАЙЛ.md"

- Секреты в коммитах запрещены: токены только в GitHub Secrets.
- docs/STATUS.md и авто-секции README вручную не редактируются — ими владеют генераторы.

## Issues

Используйте шаблоны Bug Report и Feature Request. Уязвимости — по процедуре SECURITY.md, без публичных Issue.

## Лицензия

Внося вклад, вы соглашаетесь, что он лицензируется AGPLv3 (код) и CC BY-NC 4.0 (контент).
