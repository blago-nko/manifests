# Changelog (История архитектурных изменений)

Все изменения в экосистеме фиксируются через Протоколы Архитектурных Изменений. 
Манифесты содержат только актуальное состояние (Single Source of Truth).

## [2.9-н] — 2026-08-17
### Добавлено
- SAM-INFRA-014 — управление зависимостями: NPM + GitHub Packages, запрет новых submodules.
- SAM-INFRA-015 — резервное копирование: YOS (первично), R2 после завершения плана МИГРАЦИЯ, restore drill.
- SAM-REF-016 — Knowledge Graph: domains-graph.yaml, единая таксономия, ИИ «Хранитель графа».

## [2026-08-16] Лицензирование и защита данных
- **[SAM-LIC-010]** Переход кода на GNU AGPLv3 (запрет закрытия кода), контента на CC BY-NC 4.0 (запрет коммерции).
- **[SAM-LIC-010]** Введен абсолютный запрет на перепродужу кода, контента и данных САН.
- **[SAM-LIC-010]** Разрешено цитирование ИИ-поисковиками только при наличии атрибуции и запрете экспорта (Zero Resale Policy).
- **[SAM-LIC-010]** Данные САН защищены публичной лицензией CC BY-NC-ND 4.0 с B2B-исключением по Оферте.

## [2026-08-15] Синхронизация стека и структурные правки
- **[SAM-STRUCT-004]** Исправлено несоответствие версий в метаданных и текстах манифестов.
- **[SAM-ARCH-005]** SQLite окончательно исключен из стека ГРЕК-ПАНТЕОН и СУМКа (заменен на Parquet+DuckDB).
- **[SAM-INFRA-010]** Восстановлена целостность Приложения А в САМ.md (принципы 2.3-2.4).

## [2026-08-23] Архитектурные улучшения по рекомендациям

- **[SAM-022]** Добавлено требование статического анализа (ESLint) для изоляции адаптеров. Запрет на импорт SDK сторонних вендоров вне `src/adapters/` должен обеспечиваться автоматизированно через CI/CD.
- **[GP-002]** Закреплено архитектурное требование партиционирования Parquet-файлов в Yandex Object Storage для обеспечения работы *predicate pushdown* в DuckDB.
- **[MIG-004]** Расширена пилотная фаза миграции до 2–3 сайтов разных типов для валидации скрипта `generate_redirect_map.py` на всех вариациях URL-структур.
- **[LIC-011]** Закреплено требование видимости ссылок на лицензии (AGPLv3, CC BY-NC 4.0) и правообладателя в футере всех 14 сайтов экосистемы.
- **[SUMKA-002]** Требование централизованной реализации (GitHub Action/Serverless) пайплайна обработки изображений вместо разрозненных скриптов.
