# Changelog (История архитектурных изменений)

Все изменения в экосистеме фиксируются через Протоколы Архитектурных Изменений. 
Манифесты содержат только актуальное состояние (Single Source of Truth).

## [2026-08-16] Лицензирование и защита данных
- **[SAM-LIC-010]** Переход кода на GNU AGPLv3 (запрет закрытия кода), контента на CC BY-NC 4.0 (запрет коммерции).
- **[SAM-LIC-010]** Введен абсолютный запрет на перепродужу кода, контента и данных САН.
- **[SAM-LIC-010]** Разрешено цитирование ИИ-поисковиками только при наличии атрибуции и запрете экспорта (Zero Resale Policy).
- **[SAM-LIC-010]** Данные САН защищены публичной лицензией CC BY-NC-ND 4.0 с B2B-исключением по Оферте.

## [2026-08-15] Синхронизация стека и структурные правки
- **[SAM-STRUCT-004]** Исправлено несоответствие версий в метаданных и текстах манифестов.
- **[SAM-ARCH-005]** SQLite окончательно исключен из стека ГРЕК-ПАНТЕОН и СУМКа (заменен на Parquet+DuckDB).
- **[SAM-INFRA-010]** Восстановлена целостность Приложения А в САМ.md (принципы 2.3-2.4).
