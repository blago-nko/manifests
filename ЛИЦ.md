## РАЗДЕЛ 1. ПРОГРАММНЫЙ КОД (GNU AGPLv3)
Весь исходный код экосистемы распространяется под лицензией **GNU AGPLv3**.
- **Обязанность открытия (Copyleft):** Любое лицо, использующее код (в т.ч. SaaS), обязано открыть свой производный код под AGPLv3. Закрытие кода запрещено.
- **Запрет перепродажи:** Прямая продажа кода запрещена.
- **Исключение:** Для научных проектов (см. Раздел 5) применяется лицензия MIT.

## РАЗДЕЛ 2. ОБЩЕДОСТУПНЫЙ КОНТЕНТ И МЕДИА

### 2.1. Текстовый контент и общие изображения
Распространяются под лицензией **CC BY-NC 4.0**.
- **Атрибуция (BY):** Обязательна активная ссылка на источник.
- **Запрет коммерции (NC):** Коммерческое использование запрещено.
- **Исключение:** Для научных текстов (см. Раздел 5) применяется лицензия CC BY 4.0 (разрешает коммерцию при атрибуции).

### 2.2. Специальные медиа-активы НКО (Watermarked Images)
Изображения, содержащие водяной знак НП «Общественное благополучие» или являющиеся собственными фотоматериалами основателя (например, портреты А.В. Боброва), распространяются под лицензией **CC BY-NC-ND 4.0** (No Derivatives).
- **Запрет модификаций (ND):** Запрещена обрезка, удаление водяного знака или иное изменение композиции.
- **Назначение:** Защита бренда НКО и персональных данных авторов.
- **Исключение:** Использование в социальных сетях СУМКа допускается в исходном виде с обязательной атрибуцией.

## РАЗДЕЛ 3. ДАННЫЕ ПЛАТФОРМЫ САН
- **Публично:** CC BY-NC-ND 4.0 (запрет парсинга и коммерции).
- **B2B-исключение:** Доступ для внутреннего потребления коммерческих организаций ТОЛЬКО по «Соглашению о некоммерческом сотрудничестве». Перепродажа данных САН категорически запрещена.

## РАЗДЕЛ 4. ЛИЦЕНЗИРОВАНИЕ МИГРАЦИОННЫХ СКРИПТОВ

### 4.1 Скрипты миграции данных

Все скрипты миграции (находятся в репозитории `blago-nko/manifests/scripts/`) распространяются под лицензией **GNU AGPLv3**:

- `blogger_migrator.py` — парсинг Blogger XML и генерация Markdown
- `generate_redirect_map.py` — генерация карты 301-редиректов
- `validate_redirect_map.py` — валидация карты редиректов
- `migrate_backups_to_r2.py` — перенос backup/feed.xml в Cloudflare R2
- `rollback.sh` — скрипт отката миграции

**Обязанности при использовании**:
- Любое лицо, использующее скрипты (в т.ч. SaaS), обязано открыть свой производный код под AGPLv3
- Запрещено закрытие кода модифицированных версий
- Запрещено использование в проприетарных системах без открытия исходного кода

### 4.2 GitHub Actions workflows

Workflow файлы (`.github/workflows/`) также лицензированы под **AGPLv3**:

- `enable-seo.yml` — массовое снятие noindex после миграции
- `deploy-hugo.yml` — автоматический деплой Hugo-сайтов
- `backup-r2.yml` — автоматический бэкап в R2

### 4.3 Шаблоны Hugo-тем

Hugo-темы и шаблоны (в репозитории `blago-nko/shared-assets`) лицензированы под **AGPLv3 + CC BY-NC 4.0**:

- Код шаблонов (HTML, CSS, JS) — AGPLv3
- Дизайн и графика — CC BY-NC 4.0

**Ограничения CC BY-NC 4.0**:
- Запрещено коммерческое использование дизайна
- Обязательное указание авторства
- Запрещено создание производных работ для коммерческих целей

### 4.4 Контент миграционных дампов

Сырые дампы Blogger (`backup/feed.xml`) сохраняют исходную лицензию контента:

- Текстовый контент — CC BY-NC 4.0
- Изображения — CC BY-NC 4.0 (если не указано иное)
- Код в статьях — AGPLv3

**Важно**: При миграции контента необходимо сохранить все лицензионные уведомления и атрибуты.

## РАЗДЕЛ 5. ИСКЛЮЧЕНИЯ ДЛЯ НАУЧНЫХ ПРОЕКТОВ (OPEN SCIENCE)

Для обеспечения максимальной цитируемости и открытого доступа к фундаментальным знаниям, для домена **ВАКУУМНЫЙ_КОНДЕНСАТ** (`science.obrazslov.ru`) установлено специальное двойное лицензирование, отличное от общих правил экосистемы:

### 5.1. Текст и идея научной гипотезы
Распространяется под лицензией **CC BY 4.0** (Creative Commons Attribution 4.0 International).
- **Разрешает:** Копирование, распространение, адаптацию и **коммерческое использование** материала при условии указания авторства.
- **Обоснование:** Природа фундаментальной науки требует свободного обмена знаниями без ограничений NC (NonCommercial). Ограничение коммерческого использования препятствует интеграции результатов в международные базы данных и учебные материалы.
- **Где применяется:** Все статьи, формулы, графики и текстовые описания модели вакуумного конденсата в репозитории `blago-nko/vacuum-condensate-hypothesis`.

### 5.2. Код и математические скрипты
Распространяется под лицензией **MIT License**.
- **Разрешает:** Свободное использование кода в любых целях, включая закрытые проекты и коммерческие продукты, при сохранении уведомления о лицензии.
- **Обоснование:** Привлечение внешних разработчиков и исследователей для проверки расчетов, воспроизведения симуляций и интеграции моделей в другие научные инструменты. Вирусная природа AGPLv3 могла бы отпугнуть академических партнеров.
- **Где применяется:** Python-скрипты расчетов (`scripts/*.py`), конфигурации Astro, вспомогательные утилиты сбора данных.

*(Примечание: Это явное исключение из общего правила ЛИЦ.md экосистемы blago-nko, где код защищен GNU AGPLv3, а контент — CC BY-NC 4.0).*

## Видимость лицензий на фронтенде

Для соблюдения условий двойного лицензирования и минимизации юридических рисков, на сайтах экосистемы в футере (подвале) страницы должны быть размещены ссылки на соответствующие лицензии.

### Стандартные сайты (13 RSS + Пантеон + САН + Gallery)
1. Кликабельная ссылка на файл `LICENSE` (GNU AGPLv3 — для исходного кода)
2. Кликабельная ссылка на файл `LICENSE-CONTENT` (CC BY-NC 4.0 — для контента)
3. Явное указание правообладателя: `© НП "Общественное благополучие"`

Наличие этих элементов является **обязательным критерием** прохождения `architecture-check` при деплое каждого сайта. Отсутствие хотя бы одного из пунктов блокирует релиз.

### Научный портал (science.obrazslov.ru)
1. Кликабельная ссылка на файл `LICENSE-CODE` (MIT License — для скриптов)
2. Кликабельная ссылка на файл `LICENSE-TEXT` (CC BY 4.0 — для текста)
3. Явное указание правообладателя: `© [Автор], НП "Общественное благополучие"`

### Пример разметки футера (стандартный)

```html
<footer>
<p>© НП "Общественное благополучие"</p>
<p>
Код: <a href="/LICENSE">AGPLv3</a> |
Контент: <a href="/LICENSE-CONTENT">CC BY-NC 4.0</a>
</p>
</footer>
```

### Пример разметки футера (научный)

```html
<footer>
<p>© Автор, НП "Общественное благополучие"</p>
<p>
Код: <a href="/LICENSE-CODE">MIT</a> |
Текст: <a href="/LICENSE-TEXT">CC BY 4.0</a>
</p>
</footer>
```

### Исключения по типу сайтов
- Статические Hugo-сайты: ссылки ведут на файлы в корне репозитория.
- Next.js (САН): ссылки ведут на страницы `/license` и `/license-content`.
- Blogger-витрина: ссылки в разделе "О блоге".
- Astro (Наука): ссылки ведут на файлы `LICENSE-CODE` и `LICENSE-TEXT` в корне проекта.

## ЗАКЛЮЧЕНИЕ

Лицензионный Пакет (ЛИЦ) защищает архитектуру от закрытия (AGPLv3), контент от монетизации (CC BY-NC) и базу САН от перепродажи. Исключение для научных проектов (CC BY 4.0 / MIT) обеспечивает баланс между защитой прав НКО и требованиями открытой мировой науки.
