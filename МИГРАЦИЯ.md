📋 ВВЕДЕНИЕ

Настоящий документ является сквозным техническим руководством для миграции 14 доменов экосистемы. Миграция выполняется в два этапа:

Этап 1 (Быстрый переезд): Все 14 сайтов переносятся на новую инфраструктуру в их текущем виде — 11 RSS-сайтов как статические, grekpanteon.obrazslov.ru и can.blagorussia.ru как статические дампы (RSS/Hugo static), gallery.obrazslov.ru — на Blogger с кастомным доменом.

Этап 2 (Замещение на сложные движки): После успешного переезда всей экосистемы, grekpanteon.obrazslov.ru постепенно замещается на полноценную версию на Hugo + SQLite (16 505+ страниц, ИИ-конвейер), а can.blagorussia.ru — на платформу САН на Next.js с PostgreSQL и всеми сервисами.

Архитектура и детали переноса для grekpanteon.obrazslov.ru описаны в отдельном Манифесте Грек-Пантеон, а для САН — в Манифесте САН. Настоящий манифест фокусируется на RSS-сайтах, общей инфраструктуре (DNS, хостинг, мониторинг, WAF, Image Sanitization, Blogger-витрина), SEO-преемственности и координации запуска с платформой САН и Пантеоном.

Перечень сайтов, описываемых в данном манифесте:
1. Основные порталы blagorussia.ru и obrazslov.ru;
2. Центральный хаб partnerstvo.blagorussia.ru с виджетом обратной связи;
3. Остальные тематические поддомены: obavlenia.blagorussia.ru, interesnye-mesta.obrazslov.ru, ot-gorozan.blagorussia.ru, novosti.blagorussia.ru, moisites.blagorussia.ru, joga.blagorussia.ru, ideologia.obrazslov.ru, nasa-istoria.blagorussia.ru;
4. Платформа САН (can.blagorussia.ru) – развёртывается на Vercel (PaaS) с соблюдением 152-ФЗ через российский ПДн-шлюз;
5. Сайт-витрина НКО gallery.obrazslov.ru — развёртывается на Blogger с кастомным доменом.

Сайт grekpanteon.obrazslov.ru (16 505+ страниц) описывается в отдельном Манифесте Грек-Пантеон. Его миграция выполняется синхронно с остальными доменами.

1. ВВЕДЕНИЕ (АРХИТЕКТУРНЫЕ ПРИНЦИПЫ)

Настоящий документ описывает полный цикл переноса 14 сайтов экосистемы (11 RSS + САН + Пантеон + gallery), но с разделением ответственности: RSS-сайты и общие сервисы – в данном манифесте, САН и Пантеон – в их собственных манифестах.

Специфические принципы, применяемые к RSS-сайтам и платформе САН (общие принципы см. в САМ, раздел 1.3 и Приложение А):
1. GEO-оптимизация – Тематический паспорт, Трёхуровневый Граф Знаний, JSON-LD разметка, Identity Graph.
2. E-E-A-T – Архитектура «Хаб и Спицы», двойная атрибуция, ручная корректировка ролей, раскрытие конфликта интересов.
3. Mobile-First – xs:320px, Sticky Bottom Bar, Mobile-First хлебные крошки.
4. Видео-инфраструктура – отказ от R2, мульти-загрузка на внешние платформы, Видео-Матрица РФ, двойное зеркалирование, Единый Видео-Реестр.
5. Защита от ИИ-краулеров – WAF для GPTBot, ClaudeBot, PerplexityBot, YandexAdditional.
6. Социальные ссылки – централизованный конфиг по брендам, динамические кнопки действий.
7. Аудит битых ссылок – трёхэтапная проверка с генерацией отчёта.
8. Семантические URL – новые ЧПУ с 301-редиректами, паттерн Book/Chapter.
9. Image Sanitization Pipeline – обработка изображений выполняется согласно САМ (п. 2.5).
10. Регистрация в поисковых системах – выполняется согласно САМ (п. 7.2.7).
11. Атрибуция изображений – выполняется согласно САМ (п. 2.5 и 7.2.4).
12. Поэтапная публикация – суточный лимит 200 страниц, подэтапы по батчингу ID (5000 URL/файл) для sitemap.
13. Эволюционная модель хранения медиа – выполняется согласно САМ (п. 2.4).
14. Единый стандарт фронтенда – все сайты используют shared-assets (САМ п. 1.6).
15. Политика конфиденциальности – размещается на всех 14 сайтах (САМ Приложение Г).

Инструменты разработки соответствуют единому стандарту, описанному в САМ (п. 1.4). Все компоненты экосистемы используют Open Source решения согласно этому стандарту. Подробное руководство: /docs/DEVELOPMENT_TOOLS.md.

2. КЛЮЧЕВЫЕ АРХИТЕКТУРНЫЕ КОНСТАНТЫ

Все общесистемные архитектурные константы (модель хранения, Image Sanitization, MLS-статусы, WAF, регистрация в поисковых системах, социальные ссылки, атрибуция изображений, shared-assets, Политика конфиденциальности) описаны в САМ (разделы 1.6, 2.4, 2.5, 2.6, 2.3, 7.2.7, 7.2.5, 7.2.6, 7.2.4, Приложение Г соответственно). Настоящий манифест фокусируется на специфике миграции RSS-сайтов.

Ниже приведены только константы, специфичные для миграции RSS-сайтов:
1. Источник данных – только чистые RSS/XML-фиды Blogger (для всех RSS-сайтов). Для nasa-istoria в перспективе – БД, но на этапе миграции – RSS.
2. SEO-преемственность и ЧПУ:
   * Slug генерируются на основе оригинальных URL Blogger.
   * Для новых статей и при миграции используется SlugOptimizerService (ИИ-сжатие заголовка до 5–6 ключевых слов).
   * Двойной паттерн URL: Evergreen-контент – без даты в URL: /{category}/{slug}/. Новостной/событийный контент – с датой: /{category}/{year}/{month}/{slug}/.
   * Book/Chapter Pattern: для многостраничных материалов внедряется навигация MultiVolumeNavigation.js и JSON-LD разметка Book → hasPart → Chapter.
3. Миграция без простоев – старые сайты остаются доступными до переключения DNS.
4. Управление учётными записями – разделение по доменам.
5. Раздельное управление – основная сеть с obrazslov-network; САН с can-secure-dev.
6. Единый дизайн с темизацией – 11 RSS-сайтов используют единый layout.html с data-theme.
7. Ручная корректировка авторства – приоритет: YAML-frontmatter → authors_override.json → скрипт extract_original_author.py → Матрица v4.7 (актуальная).

5. Настройка DNS: grekpanteon.obrazslov.ru → CNAME на GitHub Pages.
6. На этом этапе сайт работает как статический архив контента, доступный для пользователей и поисковых систем.

Ограничения Этапа 1:
* Отсутствует ИИ-конвейер генерации описаний
* Отсутствуют причинно-следственные связи
* Отсутствует геоинформационный слой
* Отсутствует интерактивность (комментарии, поиск, фильтрация)

7.1.9. Расширенная семантическая разметка для ИИ-поисковиков (GEO)

Для всех 14 сайтов экосистемы обязательна следующая расширенная семантическая разметка:

1. JSON-LD BreadcrumbList:
   * На всех страницах (кроме главной) обязательна разметка хлебных крошек.
   * Формат: https://schema.org/BreadcrumbList
   * Источник данных: иерархия из location_geo_path (для САН) или категорий (для RSS-сайтов и grekpanteon).

2. JSON-LD FAQPage:
   * На главных страницах и справочных разделах обязательна разметка FAQPage.
   * Минимум 5 вопросов/ответов, релевантных тематике сайта.
   * Формат: https://schema.org/FAQPage

3. Детальная разметка ImageObject:
   * Для каждого изображения на сайте обязательна разметка ImageObject.
   * Обязательные поля: contentUrl, author (с name), license, source (URL источника).
   * Формат: https://schema.org/ImageObject

4. Мета-теги для ИИ-краулеров:
   * На всех страницах устанавливается: <meta name="robots" content="max-image-preview:large">
   * Для страниц с видео добавляется: <meta property="og:video" content="...">

5. Файл ai-hints.txt:
   * На корневых доменах всех 14 сайтов размещается файл ai-hints.txt
   * Содержание: явное разрешение на цитирование материалов ИИ-поисковиками при условии указания обратной ссылки
   * Формат: plain text с четкими инструкциями для GPTBot, PerplexityBot, ClaudeBot, Google-Extended
